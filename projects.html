Projects

  • Bare-metal RTOS EDF scheduler and heap allocator on an STM32F401RE

    A real-time kernel for the STM32F401RE that runs without a vendor OS. It schedules tasks by earliest deadline first.

    It also has a custom heap allocator that merges adjacent free blocks and uses magic numbers to catch memory corruption.

  • ALIVE Biometric wearable with an adaptive game

    Capstone project: a wearable that reads biometrics and feeds an adaptive game built in Unreal Engine 5.

    My section is the biometric acquisition unit. It pairs an STM32F401RE with an ESP32 co-processor and reads a MAX30102 pulse sensor, an MPU-6050 IMU, and a galvanic skin response sensor. A fourth-order Butterworth band-pass filter cleans the signal. The unit also includes battery charging and a haptic motor driver.

  • BitWave accelerator RTL for a hardware accelerator paper

    ECE 493 team project implementing the BitWave accelerator paper.

    I own the RTL interface, memory, and integration. That includes single-port and banked SRAM modules in SystemVerilog, verified against a Python golden model with cocotb.

  • Multi-precision dot-product unit 16 lanes in SystemVerilog

    A 16-lane dot-product unit that handles FP16, BF16, TF32, FP8, MXFP8, and UINT8.

    I wrote a Python replica of the reference behavior first, then checked the RTL against test vectors until the outputs matched bit for bit.

  • FPGA matrix-vector multiplier Pipelined, eight parallel lanes

    A pipelined matrix-vector multiplier with eight parallel lanes, written in SystemVerilog.
