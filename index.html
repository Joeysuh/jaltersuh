Selected work

  1. A real-time kernel that runs without a vendor OS and schedules tasks by earliest deadline first. It has its own heap allocator that merges adjacent free blocks and uses magic numbers to catch memory corruption.

  2. A wearable that reads biometrics and feeds an adaptive game in Unreal Engine 5. I own the biometric acquisition unit: an STM32F401RE with an ESP32 co-processor, a MAX30102 pulse sensor, an MPU-6050 IMU and a galvanic skin response sensor, cleaned up by a fourth-order Butterworth band-pass filter, plus battery charging and a haptic driver.

  3. Team implementation of the BitWave accelerator paper. I wrote the single-port and banked SRAM modules in SystemVerilog and verified them against a Python golden model with cocotb.

  4. A 16-lane dot-product unit for FP16, BF16, TF32, FP8, MXFP8 and UINT8. I wrote a Python replica of the reference behavior first, then checked the RTL against test vectors until it matched bit for bit.

  5. A pipelined matrix-vector multiplier with eight parallel lanes.
